# 의료광고법 감지 — 주간 리서치 체크리스트 (Layer C)

> 목적: 하드코딩 감지(Layer A)와 LLM 심의관(Layer B)이 못 잡는 **신종·맥락 위반**을
> 주기적으로 조사하고, 감지 규칙에 추가할 **후보 목록을 리포트로만** 산출한다.
>
> ⚠️ **자동 커밋·자동 반영 금지.** 이 문서는 사람(검수팀/법무팀)이 수동으로 실행하는
> 조사 절차이며, 산출물은 "추가 후보 리포트"까지다. 실제 `medical-compliance.ts`
> 배열 수정은 **사람 승인 후 별도 PR**로만 반영한다. 코드로 강제 실행되는 크론이나
> 자동 커밋을 만들지 않는다(기존 주간 버그 점검 루틴과 충돌 없게 문서+수동 트리거 방식).

## 실행 주기

- 주간 버그 점검(매주 월요일) 루틴에 **수동 단계로 부가**한다.
- 트리거 문구 예: "의료광고법 주간 리서치" — 담당자가 아래 체크리스트를 수행.

## 체크리스트

### (a) 규제·행정처분·단속 동향 조사
- [ ] 보건복지부 보도자료 — 의료광고 관련 신규 고시·행정예고 확인
- [ ] 의료광고심의위원회(대한의사협회/대한치과의사협회/대한한의사협회) 심의 사례·반려 사유 공지
- [ ] 식품의약품안전처 — 의약품·의료기기 광고 관련 보도자료·행정처분
- [ ] 최근 의료광고법 위반 **행정처분·단속·과징금 뉴스** (지자체 보건소 처분 포함)
- [ ] 새로 문제된 표현·유형(예: SNS 체험단, 유인성 이벤트 신유형) 메모

### (b) 신규 상품명 수집
- [ ] 신규 출시·화제 **비만치료제**(전문의약품) 상품명 — 예: GLP-1 계열 신약
- [ ] 신규 **미용·시술 장비/전문시술** 상품명 — 예: 레이저·초음파·고주파 신장비
- [ ] 기존 상품명의 **변형 표기·별칭·약칭**(띄어쓰기/영문/브랜드 라인업)

### (c) 후보 리포트 산출 (반영은 사람 승인 후)
아래 두 배열에 **추가할 후보만** 표로 정리한다. 직접 코드를 수정하지 않는다.

- `PRESCRIPTION_DRUG_NAMES` (전문의약품 상품명)
- `MEDICAL_DEVICE_NAMES` (의료기기·전문시술 상품명)
- (필요 시) `PROMOTIONAL_CUES` / `WARNING_PATTERNS` / `FORBIDDEN_WORDS` 후보

리포트 양식 예:

| 구분 | 후보 표현/상품명 | 근거(출처·처분사례) | 권장 등급 | 오탐 위험 메모 |
|------|------------------|---------------------|-----------|----------------|
| 전문의약품 | (예: 신약명) | 식약처 허가/보도자료 링크 | MEDIUM(단독)/HIGH(유인) | 교육 글 오탐 여부 |
| 의료기기 | (예: 신장비명) | 심의 반려 사례 | MEDIUM/HIGH | 일반명사 충돌 여부 |
| 유인 표현 | (예: 신유형 이벤트어) | 단속 뉴스 | WARNING | 정상 문맥 충돌 |

## 반영 절차(사람)

1. 위 리포트를 검수팀/법무팀이 검토·승인.
2. 승인된 항목만 `src/content/lib/medical-compliance.ts` 배열에 추가(별도 PR).
3. 부분문자열 충돌(예: `피코` vs `피코슈어`)·일반명사 오탐 여부를 테스트로 확인.
4. `npm test` 회귀 통과 후 병합.

## 설계 근거

- **자동 반영 금지 이유**: 상품명·유인 표현은 교육/정보성 문맥에서 합법일 수 있어,
  자동 추가 시 오탐(정상 글 차단)이 급증할 수 있다. recall 은 넓히되 최종 판단은 사람이 한다.
- Layer A(키워드/정규식)·Layer B(LLM 심의관)와 **역할 분리**: Layer C 는 사람이 주기적으로
  룰셋 자체를 진화시키는 거버넌스 단계다.
